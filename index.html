Sankofa Rust sources

This is the official source repository of Sankofa Rust.

In the app: Settings > Browse > Rust sources > Add repository, then paste

https://uzeda4.github.io/sankofa-rust/index.skrepo

The app shows a fingerprint before it trusts the repository. It must be:

aca83acae150b852b62231082950406f

If it differs, do not continue. Sources are signed WebAssembly packages; see how they work and how to write one.
